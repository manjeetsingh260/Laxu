# NIGHT RUSH — Android Project

This project packages the updated NIGHT RUSH HTML game as an Android app using WebView.

## Included
- Updated NIGHT_RUSH HTML game
- App name: NIGHT RUSH
- Landscape orientation
- Fullscreen/immersive game display
- JavaScript and DOM storage enabled
- Offline local HTML asset loading

## Build in Android Studio
1. Open this folder in Android Studio.
2. Allow Gradle to sync and install any requested Android SDK components.
3. Select **Build > Build Bundle(s) / APK(s) > Build APK(s)**.
4. The debug APK will be generated under:
   `app/build/outputs/apk/debug/app-debug.apk`

## Requirements
- Android Studio with Android SDK
- Android SDK Platform 35
- A compatible JDK (Android Studio's bundled JDK is recommended)

The HTML game is stored at:
`app/src/main/assets/index.html`
